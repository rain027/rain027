### 🔭 Featured Projects

**[API Gateway with Distributed Rate Limiting](https://github.com/rain027/api-gateway)**
A config-driven reverse proxy with Redis-backed sliding-window rate limiting (atomic Lua scripts), JWT auth middleware, and full Prometheus/Grafana observability. Hardened with Helmet.js, non-root Docker execution, and Kubernetes liveness probes.
`Node.js` `Redis` `JWT` `Docker` `Kubernetes` `Prometheus` `Grafana`

**[Budget-Aware RAG for Scientific QA](https://github.com/rain027/RAG_COMPLETE)**
A retrieval-augmented QA system for scientific documents (QASPER dataset) using five-signal weighted scoring — semantic, lexical/BM25, structural, positional, and section-type — with budget-aware selection framed as a fractional knapsack problem. Evaluated at both paragraph and KILT-style sentence granularity against five baselines with paired t-tests.
`Python` `RAG` `NLP` `Information Retrieval`
